# Academic Record Management System

A comprehensive academic record management system for Cabiao Senior High School, designed to manage student grades, generate SF9 report cards, and provide secure parent access via 6-digit codes.

## Features

- **Homepage** - Parent & Student portal with 6-digit code access
- **Teacher Dashboard** - Manage students, enter grades, generate access codes
- **SF9 Report Card** - Automated grade computation following DepEd format (WW 30%, PT 50%, QE 20%)
- **Parent Portal** - Secure 6-digit code login to view child's grades
- **Grade Computation** - Real-time calculation following DepEd standards
- **PDF Download** - Download report cards as PDF

## How to Use

1. **Parents/Students:** Enter the 6-digit code from your teacher on the homepage
2. **Teachers:** Click the teacher icon (bottom-left) to access the dashboard
3. **Generate Codes:** Teachers can generate access codes for parents in the Access Codes section
